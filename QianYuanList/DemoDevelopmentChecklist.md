# Demo 开发拆分清单

## 文档目标

这份清单只服务于一个目标：

先把当前“土豆兄弟猫咪版”做出一个可玩的 `Demo`。

这里不追求完整产品，不追求全量角色和全量系统，而是优先做出：

- 能选角色
- 能打一局
- 能过波
- 能进商店
- 能买武器和道具
- 能打到 Boss
- 能失败或胜利结算

## 一、Demo 目标范围

### 1.1 Demo 版本目标

做出一个 PC 端 Unity Demo，具备完整单局闭环：

1. 进入主菜单
2. 选择角色
3. 进入战斗
4. 自动攻击并生存
5. 波次结束进入商店
6. 购买内容后进入下一波
7. 最终打到 Boss 波
8. 胜利或失败结算

### 1.2 Demo 推荐内容规模

不建议一开始就上全量内容。

建议 Demo 首版范围：

- 角色：`4-6` 个
- 武器：`8-10` 把
- 道具：`10-15` 个
- 敌人：`5-6` 个
- 波次：`8-10` 波
- Boss：`1` 个
- 商店类型：`1-2` 个
- 地图：`1` 张

### 1.3 Demo 暂不做内容

先不要做：

- 全量角色池
- 全量武器池
- 多地图主题
- 复杂剧情
- 成就系统
- 存档外成长
- 多语言
- Steam 接入
- 高成本最终美术

## 二、基于当前内容池的 Demo 推荐裁剪

### 2.1 推荐首批角色

建议先用这 `6` 个角色：

- `Well Rounded`
- `Brawler`
- `Ranger`
- `Mage`
- `Doctor`
- `Lucky`

原因：

- 覆盖均衡、近战、远程、法系、支援、经济六种明显流派
- 差异够明显
- 容易测出系统问题

### 2.2 推荐首批武器

建议先用这 `10` 把武器：

- `Toy Rod`
- `Toy Rod Plus`
- `Claw`
- `Claw Plus`
- `Paw Glove`
- `Feather Dart`
- `Purr Staff`
- `Charm Bell`
- `Laser Pointer`
- `Water Orb`

原因：

- 覆盖近战、远程、法系、功能型
- 已有升级链，方便测试商店与成长

### 2.3 推荐首批道具

建议先用这 `12` 个道具：

- `Catnip Bundle`
- `Dried Sardine Pack`
- `Wheatgrass Pot`
- `Scratching Board`
- `Sunbeam Cushion`
- `Climbing Shelf`
- `Paper Box Fort`
- `Quiet Blanket`
- `Grooming Brush`
- `Black Cat Amulet`
- `Laser Battery`
- `Fish Fountain`

原因：

- 覆盖攻击、防御、回复、机动、幸运、经济
- 足够支撑 Demo 构筑体验

### 2.4 推荐首批敌人

建议先用这 `6` 个敌人：

- `Stray Dog`
- `Shadow Puff`
- `Alley Snake`
- `Robot Vacuum`
- `Noise Speaker`
- `Dog Alpha` 作为 Boss

原因：

- 包含追击、扰动、伏击、区域压制、Boss 压迫
- 行为差异够明显

### 2.5 推荐波次结构

建议 Demo 波次做 `10` 波：

1. 教学波
2. 基础混合波
3. 伏击敌人引入
4. 机器人引入
5. 第一精英压力波
6. 混合波
7. 区域压制波
8. 高压波
9. Boss 前整理波
10. Boss 波

## 三、Demo 必做内容清单

## 3.1 工程基础

必须完成：

- Unity 项目建立
- 基础目录结构建立
- 场景结构建立
- 配置表导入方式确定
- 输入系统接入
- 基础调试日志可用

建议场景：

- `Scene_Boot_Init`
- `Scene_Menu_Main`
- `Scene_Battle_Core`

## 3.2 玩家控制模块

必须完成：

- WASD/方向键移动
- 玩家属性读取
- 生命值系统
- 受击与死亡
- 拾取材料
- 基础碰撞

## 3.3 自动攻击模块

必须完成：

- 自动索敌
- 自动攻击
- 攻击冷却
- 近战命中
- 远程弹道
- 伤害计算
- 暴击计算

## 3.4 武器模块

必须完成：

- 武器装备
- 武器攻击逻辑
- 多武器并存
- 武器升级或合成
- 武器稀有度显示

Demo 阶段可以简化：

- 先不做特别复杂的武器特化行为
- 先保证基础武器手感成立

## 3.5 敌人与刷新模块

必须完成：

- 敌人出生
- 敌人寻路或追击
- 敌人接触伤害
- 敌人死亡
- 敌人掉落材料
- 波次定时刷新
- Boss 出场

## 3.6 波次模块

必须完成：

- 波次开始
- 波次倒计时
- 敌人池读取
- 波次结束判定
- 商店切换
- 最终 Boss 波切换

## 3.7 商店模块

必须完成：

- 波次结束进入商店
- 随机展示武器和道具
- 刷新
- 锁定
- 购买
- 金币或材料扣除
- 下一波按钮

Demo 阶段建议：

- 先只做一个普通商店
- 特殊商店先预留，不强行上线

## 3.8 道具模块

必须完成：

- 被动物品获取
- 属性即时生效
- 持续效果处理
- 开波触发
- 过波触发

Demo 阶段建议：

- 先支持 `passive / on_wave_start / on_wave_end`
- `on_hit / on_take_damage` 后补

## 3.9 UI 模块

必须完成：

- 主菜单
- 角色选择界面
- 战斗 HUD
- 生命值条
- 材料显示
- 当前波次显示
- 倒计时显示
- 商店界面
- 结算界面

## 3.10 反馈模块

必须完成：

- 命中数字
- 受击闪白或闪红
- 敌人死亡反馈
- 掉落拾取反馈
- 波次结束提示
- Boss 警告提示

## 3.11 音频模块

Demo 阶段最低要求：

- 战斗 BGM
- 商店 BGM
- 命中音效
- 敌人死亡音效
- 拾取音效
- UI 点击音效
- Boss 提示音效

## 四、Demo 开发步骤

## 第 1 步：搭工程骨架

你要完成：

- 创建 Unity 工程
- 建立标准目录
- 建立 Boot/Menu/Battle 三个场景
- 导入输入系统
- 确定配置表读取方式

完成标准：

- 工程可正常启动
- 可从主菜单进入战斗场景

## 第 2 步：先做战斗底层

你要完成：

- 玩家移动
- 摄像机跟随
- 基础属性类
- 生命值与受伤逻辑
- 材料拾取

完成标准：

- 角色能移动
- 能掉血
- 能死亡
- 能拾取材料

## 第 3 步：接入自动攻击系统

你要完成：

- 自动索敌
- 近战伤害
- 远程投射物
- 攻击冷却
- 基础伤害公式

完成标准：

- 玩家不用手动攻击也能正常输出
- 至少 1 把近战武器和 1 把远程武器能跑通

## 第 4 步：做敌人与波次

你要完成：

- 敌人出生器
- 敌人移动逻辑
- 普通敌人死亡
- 波次倒计时
- 波次结束

完成标准：

- 至少能完成 3 波基础循环

## 第 5 步：做商店

你要完成：

- 波次后进入商店
- 刷新候选
- 购买武器
- 购买道具
- 锁定商品
- 进入下一波

完成标准：

- 一局里能形成至少一次明显构筑选择

## 第 6 步：接入首批角色和内容池

你要完成：

- 接入 4-6 个角色
- 接入 8-10 把武器
- 接入 10-15 个道具
- 接入 5-6 个敌人

完成标准：

- 角色之间已有明显差异
- 商店能刷出多种不同构筑路线

## 第 7 步：做 Boss 波和结算

你要完成：

- Boss 出场逻辑
- Boss 基础技能
- 胜利界面
- 失败界面
- 返回菜单

完成标准：

- Demo 能完成完整一局

## 第 8 步：补 UI 与反馈

你要完成：

- 主界面优化
- HUD 补齐
- 商店可读性提升
- 命中与受击反馈
- 音效补充

完成标准：

- 不靠解释也能完整玩一局

## 第 9 步：打包和试玩测试

你要完成：

- 打 Windows Demo 包
- 自测 5-10 局
- 修复阻塞 Bug
- 检查性能和卡死问题

完成标准：

- Demo 可稳定运行
- 没有明显阻塞性问题

## 五、建议开发顺序

严格建议按这个顺序做：

1. 工程结构
2. 玩家移动和生命
3. 自动攻击
4. 敌人和波次
5. 商店
6. 武器和道具
7. 角色差异
8. Boss
9. UI 和反馈
10. 打包测试

不要倒着做。

不要先做这些：

- 精美 UI
- 最终立绘
- 大量特效
- 大量角色扩充
- Steam 集成

## 六、Demo 阶段的最低验收标准

只要满足下面这些，就算 Demo 成立：

- 可以选角色
- 可以进入战斗
- 可以自动攻击
- 可以过波
- 可以进商店
- 可以购买武器和道具
- 可以打到 Boss
- 可以胜利或失败结算
- 不会频繁报错或卡死

## 七、你现在最该先做的 3 件事

1. 先把 `Battle` 场景的基础循环做出来
2. 先接入 `CharacterConfig / WeaponConfig / EnemyConfig / WaveConfig`
3. 先保证 `前 3 波 + 商店` 能完整跑通

只要这三件事做出来，Demo 就真正起步了。
