# Unity Demo 开发任务拆分

## 文档目标

这份文档把 `DemoDevelopmentChecklist.md` 进一步拆成可执行任务。

目标不是继续讲方案，而是明确：

- 先做什么
- 后做什么
- 每一步完成标准是什么
- 哪些内容是 `P0` 必做
- 哪些内容是 `P1` 可延后

## 一、总原则

### 1.1 优先级规则

- `P0`：没有它 Demo 跑不起来
- `P1`：Demo 能跑，但没有它体验会差
- `P2`：锦上添花，Demo 首版可以不做

### 1.2 开发节奏规则

严格按这个顺序推进：

1. 跑通单局基础循环
2. 再接入内容池
3. 再补 UI 和反馈
4. 最后再打磨体验

## 二、阶段拆分

## 阶段 A：工程初始化

### A-01 创建 Unity 工程

- 优先级：`P0`
- 内容：创建项目，确定渲染管线，确认输入系统
- 输出：可启动的空工程
- 完成标准：Unity 工程可正常打开，无报错

### A-02 建立目录结构

- 优先级：`P0`
- 内容：按 `UnityEngineeringSpecification.md` 建立 `Scenes / Scripts / Prefabs / Data / UI / Audio / VFX`
- 输出：标准目录树
- 完成标准：目录结构稳定，不再临时乱放资源

### A-03 创建基础场景

- 优先级：`P0`
- 内容：创建 `Boot / Menu / Battle`
- 输出：3 个基础场景
- 完成标准：能从 `Boot` 进入 `Menu`，再进入 `Battle`

### A-04 接入配置表读取

- 优先级：`P0`
- 内容：确定 CSV 或 Excel 导入方式，至少能读 `Character/Weapon/Enemy/Wave`
- 输出：基础配置读取模块
- 完成标准：启动时能正确加载配置并打印条目数量

### A-05 建立基础调试工具

- 优先级：`P1`
- 内容：调试日志、临时参数面板、快速重开、切波快捷入口
- 输出：基础 Debug 工具
- 完成标准：开发阶段能快速验证角色、敌人、波次

## 阶段 B：战斗底层

### B-01 玩家移动

- 优先级：`P0`
- 依赖：`A-01` `A-03`
- 内容：WASD/方向键移动，基础朝向处理
- 输出：玩家控制器
- 完成标准：角色能稳定移动，无明显卡顿和穿模

### B-02 摄像机跟随

- 优先级：`P0`
- 依赖：`B-01`
- 内容：主摄像机跟随角色
- 输出：基础战斗视角
- 完成标准：战斗中角色始终处于合理视野范围

### B-03 生命与受击系统

- 优先级：`P0`
- 依赖：`B-01`
- 内容：玩家 HP、受伤、死亡、无敌帧基础逻辑
- 输出：角色生存系统
- 完成标准：角色能扣血、死亡、触发失败

### B-04 材料拾取系统

- 优先级：`P0`
- 依赖：`B-03`
- 内容：材料掉落、吸附或拾取、数量累加
- 输出：局内货币系统
- 完成标准：敌人死亡后材料可被玩家获取并累计

### B-05 基础属性模块

- 优先级：`P0`
- 依赖：`A-04`
- 内容：生命、护甲、闪避、近战伤害、远程伤害、攻速、幸运、收获等
- 输出：统一属性容器
- 完成标准：属性能被角色、武器、道具共同读写

## 阶段 C：自动攻击与武器

### C-01 自动索敌

- 优先级：`P0`
- 依赖：`B-05`
- 内容：查找最近目标或有效目标
- 输出：通用索敌逻辑
- 完成标准：角色在攻击范围内能稳定找到目标

### C-02 近战攻击

- 优先级：`P0`
- 依赖：`C-01`
- 内容：近战命中判定、伤害触发、攻击冷却
- 输出：近战武器基础逻辑
- 完成标准：`Toy Rod / Claw / Paw Glove` 至少 1 把能完整工作

### C-03 远程攻击

- 优先级：`P0`
- 依赖：`C-01`
- 内容：投射物生成、飞行、命中、销毁
- 输出：远程武器基础逻辑
- 完成标准：`Feather Dart / Laser Pointer / Water Orb` 至少 1 把能完整工作

### C-04 武器装备系统

- 优先级：`P0`
- 依赖：`C-02` `C-03`
- 内容：装备槽、武器列表、多个武器并存
- 输出：武器容器
- 完成标准：角色可同时持有多把武器并轮流攻击

### C-05 武器升级链

- 优先级：`P1`
- 依赖：`C-04`
- 内容：同类武器升级或合成
- 输出：基础升级机制
- 完成标准：能从 `Toy Rod` 升到 `Toy Rod Plus`

## 阶段 D：敌人与波次

### D-01 普通敌人基础 AI

- 优先级：`P0`
- 依赖：`B-03`
- 内容：追击、接触伤害、死亡
- 输出：基础敌人逻辑
- 完成标准：`Stray Dog` 可以完整跑通

### D-02 特殊行为敌人

- 优先级：`P1`
- 依赖：`D-01`
- 内容：扰动型、伏击型、区域压制型
- 输出：差异化敌人行为
- 完成标准：至少再接 `Shadow Puff`、`Robot Vacuum`、`Noise Speaker`

### D-03 敌人掉落

- 优先级：`P0`
- 依赖：`D-01`
- 内容：死亡掉落材料
- 输出：敌人经济回路
- 完成标准：不同敌人掉落数量可配置

### D-04 波次控制器

- 优先级：`P0`
- 依赖：`A-04` `D-01`
- 内容：倒计时、刷新池、刷新预算、波次结束切换
- 输出：波次系统
- 完成标准：前 3 波能自动连续运行

### D-05 精英与 Boss

- 优先级：`P1`
- 依赖：`D-04`
- 内容：精英波、Boss 波、Boss 出场逻辑
- 输出：高压战斗段
- 完成标准：`Dog Alpha` 能作为 Boss 正常出场

## 阶段 E：商店与道具

### E-01 商店基础界面

- 优先级：`P0`
- 依赖：`D-04`
- 内容：波次结束进入商店、显示可购买内容
- 输出：基础商店 UI
- 完成标准：每波后可正常进入商店

### E-02 商店购买逻辑

- 优先级：`P0`
- 依赖：`E-01`
- 内容：购买武器、购买道具、扣除材料
- 输出：可交互商店
- 完成标准：购买后内容立即进角色背包或属性系统

### E-03 商店刷新与锁定

- 优先级：`P1`
- 依赖：`E-02`
- 内容：刷新价格、锁定商品、进入下一波
- 输出：基础决策系统
- 完成标准：商品刷新和锁定都生效

### E-04 道具被动生效

- 优先级：`P0`
- 依赖：`B-05` `E-02`
- 内容：`passive` 类型道具即时生效
- 输出：基础道具效果系统
- 完成标准：购买 `Dried Sardine Pack` 等能立刻改变角色属性

### E-05 道具触发生效

- 优先级：`P1`
- 依赖：`E-04`
- 内容：`on_wave_start`、`on_wave_end`
- 输出：事件型道具效果
- 完成标准：`Catnip Bundle`、`Wheatgrass Pot` 正常生效

## 阶段 F：角色接入

### F-01 角色选择界面

- 优先级：`P0`
- 依赖：`A-03` `A-04`
- 内容：角色列表、选中进入战斗
- 输出：角色选择 UI
- 完成标准：可选择首批 Demo 角色

### F-02 角色属性加载

- 优先级：`P0`
- 依赖：`F-01` `B-05`
- 内容：开局属性、起始武器、角色被动
- 输出：角色初始化逻辑
- 完成标准：不同角色进入战斗后属性明显不同

### F-03 首批 6 角色接入

- 优先级：`P1`
- 依赖：`F-02`
- 内容：接入推荐的 6 个 Demo 角色
- 输出：首批可玩角色组
- 完成标准：角色流派差异明显

## 阶段 G：UI 与反馈

### G-01 战斗 HUD

- 优先级：`P0`
- 依赖：`B-03` `D-04`
- 内容：血量、材料、波次、倒计时
- 输出：战斗 HUD
- 完成标准：核心信息都能被玩家看见

### G-02 商店 UI 完善

- 优先级：`P0`
- 依赖：`E-01`
- 内容：商品卡片、价格、描述、刷新按钮、下一波按钮
- 输出：可读商店
- 完成标准：玩家不靠说明也能完成一次购买

### G-03 结算界面

- 优先级：`P0`
- 依赖：`B-03` `D-05`
- 内容：胜利、失败、返回菜单
- 输出：闭环界面
- 完成标准：一局结束后能正常退出或重开

### G-04 命中与受击反馈

- 优先级：`P1`
- 依赖：`C-02` `C-03` `D-01`
- 内容：伤害数字、受击闪烁、敌人死亡反馈
- 输出：基础爽感反馈
- 完成标准：战斗体验不再“打中了但没感觉”

## 阶段 H：音频与打包

### H-01 最低音频接入

- 优先级：`P1`
- 内容：战斗 BGM、商店 BGM、命中音效、UI 点击音效
- 输出：基础声音层
- 完成标准：至少战斗和商店不再静音

### H-02 Windows Demo 打包

- 优先级：`P0`
- 内容：出 PC 包、检查运行目录
- 输出：Demo 可执行包
- 完成标准：能在本机独立启动和游玩

### H-03 自测修 Bug

- 优先级：`P0`
- 内容：连续试玩 5-10 局，记录阻塞 Bug
- 输出：首轮修复清单
- 完成标准：无频繁崩溃、无明显流程阻塞

## 三、推荐开发顺序

## 第 1 轮：只跑通主循环

必须完成：

- `A-01` ~ `A-04`
- `B-01` ~ `B-05`
- `C-01` ~ `C-04`
- `D-01` ~ `D-04`
- `E-01` ~ `E-02`
- `G-01`

完成后结果：

- 能打一局基础循环
- 能进商店
- 能进入下一波

## 第 2 轮：把 Demo 内容接进去

必须完成：

- `E-04`
- `F-01` ~ `F-03`
- 首批 4-6 角色接入
- 首批 8-10 武器接入
- 首批 10-15 道具接入
- 首批 5-6 敌人接入

完成后结果：

- Demo 已经具备流派差异

## 第 3 轮：补 Boss、商店决策和结算

必须完成：

- `C-05`
- `D-05`
- `E-03`
- `E-05`
- `G-02`
- `G-03`

完成后结果：

- 一局有完整前中后期结构

## 第 4 轮：补体验

建议完成：

- `G-04`
- `H-01`
- `H-02`
- `H-03`

完成后结果：

- Demo 可以给别人试玩

## 四、最小 Demo 验收标准

只要下面都满足，就可以认为 Demo 成立：

- 能选角色
- 能进入战斗
- 能自动攻击
- 能刷敌人
- 能完成至少 8 波
- 能进入商店并购买
- 能打 Boss
- 能胜利或失败结算
- 打包后能稳定运行

## 五、你现在立刻可以开始做的任务

如果只看“今天先做什么”，建议按这个顺序开工：

1. `A-01` 创建 Unity 工程
2. `A-02` 建目录
3. `A-03` 建场景
4. `A-04` 读配置表
5. `B-01` 做角色移动
6. `B-03` 做生命和受击
7. `C-01` 做自动索敌
8. `C-02` 做一把近战武器
9. `D-01` 做一个基础敌人
10. `D-04` 做前 3 波

这 10 个任务做完，你的 Demo 就真正起步了。
